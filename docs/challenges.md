# 自主修改挑戰

完整專案從第一分鐘就可讀、可跑；看懂後可直接選題，不需要等全班進度。先保留原輸入與成果，再修改及重跑。

## 快速起步

- 複製 sensor-demo.json，改 title，輸出到新資料夾，開啟 PPTX 找到差異。
- 改 theme.accent，再生成第二份配色。
- 換 sensor-updated.json，比對圖表與統計值，確認工具和配圖沒有重做。

## 工具修改

- 在 add_samples 將折線圖改為另一種適用的原生圖表，核對資料未變。
- 在 statistics 增加一個確定定義的指標，於 add_results 顯示，再補上結果檢查。
- 調整 add_architecture 的版型，保持圖形可編輯且不超出頁面。

## 素材整合

沿用 image-prompt.md 修改配圖主題，生成後保存另一檔名，以 --hero 指定新圖。開啟簡報確認新圖被使用。配圖只是示意，精確數據與結構仍由程式建立。

## 自主擴充

可以增加一個 add_* 函式或輸出工具，再調整 SKILL.md 與驗證。原版固定六頁，變更頁數時要同步修改檢查規格，並提供可重現範例。

完成證據：修改後的檔案、實際 PPTX、一項可核對差異，以及讓同學重跑的命令。若有新功能，寫清楚適用範圍與限制。
