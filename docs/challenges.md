# 直接修改的任務

## 修改一頁

改香草版的一個標題，讓 Agent 用 imagegen 重新生成該頁。保留實際 Prompt，對照原文核對，輸出新 PPTX。只改 JSON 或重新封裝舊圖不算完成。

## 修改視覺

將科技風改成你指定的另一種風格。先改規則與 Prompt，再用 imagegen 生成新的整頁參考，重新生成至少兩頁，檢查它們是否一致。不能用程式重新著色圖片代替生圖。

## 增加頁面

在原稿增加第五頁並重新抽取。讓 Agent 選頁型並用 imagegen 生成，確認組裝工具可接受五頁、檢查工具能發現漏頁。

## 修改工具

讓 Agent 改善抽取程式的一個具體功能，例如更清楚地記錄表格位置，並用實際 PPTX 驗證。不要把設計頁面的工作移入 Python。

## 完成證據

保留原稿、實際 Prompt、新 PNG、新 PPTX 與檢查結果，讓同學知道改了什麼。不要把別人先前生成的範例宣稱為自己的新生圖結果。
