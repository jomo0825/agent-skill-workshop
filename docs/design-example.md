# Agent Skill 設計單｜完整填寫範例

姓名／組別：課程示範　日期：2026-11-19　Skill 名稱：weekly-assistant

## 一、使用者與工作需求

| 欄位 | 填寫範例 |
|---|---|
| 使用者 | 同時上課、工作與安排生活的產學專班學生 |
| 問題 | 行程可能撞期，作業與面試準備容易忘記安排 |
| 一句話任務 | 根據固定行程、待辦與偏好，產生含衝突提醒的一週生活計畫 |
| 應使用的請求 | 請用 demo.json 幫我規劃 2026-11-23 那週，列出撞期和沒排進去的事 |
| 不適用情境 | 即時訂票、真正寄信、修改 Google Calendar、跨夏令時間地區的複雜排程 |

## 二、輸入與輸出

| 項目 | 內容／格式 | 缺少時處理 |
|---|---|---|
| 固定行程 | JSON events，包含 id、title、start、end | 真實任務詢問；明確沒有行程則給空清單 |
| 待辦 | JSON tasks，包含 id、title、minutes、priority、due | 缺期限或所需時間就詢問，不自行猜測 |
| 偏好與起始日 | workdays、windows、週一日期 | 詢問；體驗範例時明示使用範例設定 |
| 輸出 | plan.json 與含嵌入圖片的 week-plan.html | 輸出失敗則回報，不宣稱完成 |

## 三、工作流程與分工

| 步驟 | 工作 | 執行者 | 可檢查的結果 |
|---|---|---|---|
| 1 | 確認日期與資料 | Agent／使用者 | 完整 JSON 與週一起始日 |
| 2 | 檢查欄位、計算衝突與安排待辦 | Python | plan.json |
| 3 | 建立個人助理風格橫幅 | 影像工具，於製作 Skill 時使用 | assets/banner.png |
| 4 | 將排程結果與既有圖片組成報告 | Python | week-plan.html |
| 5 | 說明衝突與未安排原因 | Agent | 根據 JSON 的摘要與實際檔案連結 |

## 四、程式工具規格 → scripts/

- 程式：planner.py，負責規則明確的排程與 HTML 輸出。
- 參數：--input JSON 路徑、--week 週一日期、--out 輸出資料夾。
- 規則：固定行程不移動；依優先級、期限及 id 排序待辦，安排在期限前最早可容納的連續空檔。
- 命令（專案根目錄）：

  ```sh
  python .agents/skills/weekly-assistant/scripts/planner.py --input data/demo.json --week 2026-11-23 --out output/demo
  ```

- 輸出：output/demo/plan.json 與 output/demo/week-plan.html。
- 失敗：退出碼 2 並顯示錯誤。Python 只需標準函式庫。
- 核對：範例應有 1 組固定行程衝突、4 項已安排、2 項未安排；第一項待辦於週一 13:00 開始。

## 五、影像與其他素材 → assets/

- 素材：banner.png，個人週計畫報告橫幅。
- 提示詞：溫暖紙感插畫，個人助理桌面、週計畫本、筆電、植物與小機器人；米白底、低彩度青綠與暖橘，約 3:1 橫幅，左側留白，不要文字、數字或商標。
- 生成時機：製作或換風格時；一般每週執行沿用原圖。
- 驗收：主題清楚、沒有錯誤文字、橫幅裁切後仍可辨識；實際打開報告檢查。
- 完整生成提示詞保存於 assets/image-prompt.md。

## 六、參考規則 → references/

- rules.md：JSON 欄位、時間與排程規則、輸出說明。
- 限制：固定 UTC+08:00、待辦不拆分、無交通緩衝、貪婪排程不保證最佳。

## 七、例外與行動範圍 → SKILL.md

- 缺必要資訊：真實任務詢問；教學示範明示使用虛構資料。
- 程式失敗：指出錯誤欄位或檔案，修正後重跑。
- 找不到圖片：還原教學素材或產生新圖，成功後再重跑。
- 行動範圍：只產生建議報告，不修改真實日曆、不寄送訊息。
