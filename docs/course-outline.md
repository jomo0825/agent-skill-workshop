# 三小時技術課程｜投影片生成大師

工程／資訊背景產學專班。教師提供固定內容、數據與版型，學生直接取得完整 Skill 和成品。先看、先跑、先改，不要求從空白開始。

## 第一章　成品展示與 Skill 原始碼導覽（25 分鐘）

### 先看成品與 SKILL.md（5 分鐘）
開啟六頁簡報，示範一次實際執行，直接打開完整 SKILL.md。

### 順著指示找 scripts、assets、references（10 分鐘）
從一行呼叫追到 Python，對照配圖與輸入格式；不逐行講完所有程式。

### 自己跑一次並修改（10 分鐘）
修改一個標題或數值後重跑。已跑通者直接選挑戰，需要協助者查閱後續說明。

## 第二章　用 Agent 製作 Python 投影片工具（65 分鐘）

### 讀取內容並產生投影片（20 分鐘）
追蹤 JSON 到 add_* 函式的資料流，讓 Agent 依固定版型產生或修改一個功能。

### 以 Python 產生技術圖表（20 分鐘）
從模擬測試數據建立原生圖表，檢查單位、數值及加入投影片的位置。

### 封裝為可重用工具（25 分鐘）
讀懂參數、路徑及錯誤回報，從 Skill 呼叫腳本並核對結果。

## 休息（10 分鐘）

## 第三章　素材整合、Skill 封裝與驗證（80 分鐘）

### 生成並保存配圖（25 分鐘）
參考 assets/image-prompt.md 製作新配圖，保存並使用 --hero 載入。無生圖能力者沿用隨附素材。

### 整合與修改（35 分鐘）
串接資料、圖表與配圖，換標題、數據或 accent 重跑。依能力修改版型或增加工具。

### 驗證與分享（20 分鐘）
開檔檢查內容、溢出與可編輯性，使用檢查腳本，換第二份輸入再執行，整理可重現專案。

25 + 65 + 10 + 80 = 180 分鐘。已能自主操作的學生可直接進入挑戰，教師依遇到的問題提供技術支援。課程不包含需求訪談、聽眾分析或設計單教學。
