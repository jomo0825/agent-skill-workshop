# 三小時課程大綱｜Agent Skill 設計與實作

對象：工程／資訊背景的產學專班學生。目標：能讀懂完整範例、修改需求、封裝工具與素材，並用新資料驗證。

## 第一章　Agent Skill 的概念與生活應用（15 分鐘）

### 第一節　從一次性任務到可重複執行的能力
辨認值得封裝的重複工作。

### 第二節　Agent、Prompt、Skill 與工具的分工
理解指示、執行工具與可重用資源如何合作。

### 第三節　案例展示：我的一週生活助理
從上課、看牙、打球、作業與面試準備，展示時間衝突提醒、待辦安排與個人週計畫。先看完整成果，再進入原始碼。

## 第二章　用設計單規劃 Skill（25 分鐘）

### 第一節　從完整範例反推需求
對照 design-example.md 與成品，辨認使用者、目標與適用範圍。

### 第二節　定義輸入、輸出與驗收條件
閱讀範例 JSON，將「幫我安排一下」改成可執行規格。

### 第三節　拆解流程並決定分工
區分 Agent 的理解與說明、Python 的確定性處理、影像工具的素材製作。

### 第四節　從設計單對應檔案結構
將規格對應至 SKILL.md、scripts、assets 與 references。

### 第五節　實作：複製空白設計單並修改需求
以既有範例為底，修改兩項個人偏好與一項驗收條件。

## 第三章　讓 Agent 製作與使用 Python 工具（35 分鐘）

### 第一節　讀懂可執行範例的資料流
從 JSON 經 validate、build_plan、render_html 到報告，不逐行講語法。

### 第二節　示範 Agent 依規格產生一個小函式
以相鄰行程與重疊判斷為例，在另存的練習檔示範「需求 → 生成 → 執行 → 修正」，不覆寫已驗證範例。

### 第三節　將程式封裝到 scripts
說明參數、退出碼與輸出；區分本機腳本和註冊工具。

### 第四節　用小型案例驗證程式
測試相鄰行程、跨週行程、到期時間與缺漏欄位。

### 第五節　實作：讀懂並修改既有程式或設定
先完成一鍵執行，再修改可用時段；進階學生再加入交通緩衝。

## 中場休息（10 分鐘）

## 第四章　讓 Agent 生成並重用影像素材（30 分鐘）

### 第一節　個人助理需要哪些視覺素材
認識週報橫幅、角色插圖與範本的實際用途。

### 第二節　從用途撰寫影像生成需求
指定風格、構圖、比例與無文字要求。

### 第三節　示範生成、預覽與保存
依 assets/image-prompt.md 示範，將選定圖片保存到 assets。

### 第四節　實作：更換個人週報風格
更換圖片並重跑報告，確認圖片真正出現在成果裡。無生成權限者使用隨附素材。

### 第五節　區分素材製作與日常執行
說明為什麼每週換資料不必重生圖，也不必重寫程式。

## 第五章　整合實作：完成我的一週生活助理 Skill（45 分鐘）

### 第一節　閱讀並調整 SKILL.md
理解使用時機、必要資訊、程式路徑與操作順序。

### 第二節　串接資料、Python 與素材
讓 Agent 使用範例 Skill，產出實際檔案。

### 第三節　檢查個人週計畫與提醒
確認看牙與上課撞期、過期待辦與長任務未安排原因。

### 第四節　個人化需求與錯誤修正
改用匿名模擬資料、更換可用時段、修正一個執行問題。

### 第五節　換一週資料重跑
使用 second-week.json，證明重用的是既有 Skill、程式與素材。

## 第六章　驗收、分享與產業延伸（20 分鐘）

### 第一節　依設計單驗收成果
檢查輸出正確、限制清楚、工具與素材確實被使用。

### 第二節　分辨問題應修在哪一層
區分指示、程式、資料與素材問題。

### 第三節　成果分享與修正紀錄
分享一項個人化變更與驗證證據。

### 第四節　遷移到產業工作
將同樣的設計方法延伸到工單整理、測試報告或值班排程；只討論差異，不在本堂重建第二個專案。

## 時間配置與成果

15 + 25 + 35 + 10 + 30 + 45 + 20 = 180 分鐘。

學生繳交：填妥的設計單、修改後的 Skill、HTML 與 JSON、一次修正或變更的驗證紀錄。採「先跑成果 → 看懂 → 改一項 → 再驗證」的方式，不要求從空白專案起步。
