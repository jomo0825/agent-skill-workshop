# 課堂展示：先看成品，再看 Skill

## 1. 一開始就展示結果

打開 `examples/preview.md`，比較四頁原稿與成品。展示完整 `SKILL.md` 的六個部分，再打開其連到的腳本、視覺參考與規則，不逐行講完所有程式。

先問學生：哪部分是 imagegen 做的？哪部分 Python 做的？指向「整張完成圖片」與「圖片封裝」的分界。

## 2. 先讓所有人成功跑一次

跟著 README 路線 A 執行，不需要現場等待生圖。開啟 `output/reproduced.pptx`，確認四頁完整畫面。這是使用隨附生圖結果的重現示範，不是一次新的 AI 生成。

## 3. 實際示範 imagegen

用 PowerPoint 修改香草版的一頁標題，另存 `output/changed.pptx`。請 Agent 讀 Skill，在新工作資料夾抽取原稿，再為修改頁寫 Prompt，以 imagegen 生成完整新頁面。保留其他已核對且內容未變的頁圖，封裝為新 PPTX，並核對改字是否正確。若需要整份不同風格，逐頁重新生成。

生圖等候期間可以看 `references/asset-prompts.md`，指出逐字內容、頁型描述及參考圖的作用。沒有 imagegen 權限的學生使用隨附頁面繼續練習腳本，課後再到有權限的環境完成重製。

## 4. 對照工具輸出

`source.json` 是讀取紀錄，並不是投影片設計語言。`notes` 提供視覺指引，不直接顯示。`source_sha256` 防止抽取後原稿已被更動卻沿用舊記錄。腳本發現複雜物件時會提示檢視原稿，但不保證自動找到所有母片與背景內容。

`check_deck.py` 只檢查結構與圖片一致性，不會判讀中文字，也不會呼叫 imagegen。以一個有錯字的圖片說明：即使檔案結構通過，仍須重新生圖修正。

## 5. 學生直接前進

已看懂者直接選修改任務；其他同學沿腳本資料流繼續理解。課堂不要求先填設計單、訪談需求或自行研究簡報主題。
