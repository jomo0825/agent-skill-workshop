# 素材生成紀錄

本組素材使用內建 imagegen 產生，共五次呼叫。風格總覽為全新生成；四頁範例以風格總覽作視覺參考，每頁獨立生成完整畫面。沒有使用 Rinne 圖片或角色，不以程式拼貼或疊字製作投影片。這些是可修改的實際 Prompt。

## 風格總覽

```text
Use case: productivity-visual
Asset type: reusable slide style reference board for a university Agent Skill workshop.
Create one polished 16:9 visual style board, not a presentation page or multiple slide thumbnails. Original futuristic information design, no anime characters, no existing brands. Split a unified composition into a deep midnight navy region and an airy white region, connected by precise cyan rails and restrained magenta angular accents. Show abstract luminous data pathways, one elegant glass prism, a small set of angular header silhouettes, and five restrained color swatches. Clear, uncluttered, sophisticated sci-fi classroom identity with ample blank space, thin lines, strong legibility.
Text (verbatim): "SLIDE MASTER" and "VISUAL SYSTEM". No other text, no pseudo text, no watermark. Colors #090E24 #172342 #16D9EC #EE4EAD #FFFFFF. Consistent geometry for later cover, concept, process and comparison pages. Flat front-facing artwork, full bleed, 16:9.
```
