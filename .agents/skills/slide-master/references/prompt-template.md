# 逐頁生成 Prompt 範本

先讀抽取內容並檢視原稿。每頁保存一份實際使用的 Prompt，交給 imagegen 生成完整畫面；模板內的大括號須換成真實資料。參考素材只用來引導風格，不能拼貼成頁面。

```text
用途：產生一張最終投影片圖片，16:9 橫式，正面滿版。
原稿參考：{本頁原稿預覽路徑，用來核對內容}
風格參考：{style-board.png 與本頁適用的頁型範例}
保留的來源圖片：{檔案與用途，沒有則寫無}
頁型與版面：{封面／概念／流程／比較，描述資訊如何安排}
視覺：午夜藍、白色、青色、少量洋紅。切角與細線，清楚且有留白。
Text (verbatim)：
{逐行貼上本頁全部可見原文，含標題、內文、標示與數值}
限制：原文逐字保留，只能調整換行。不可添加口號、頁碼、假文字或浮水印。
所有文字都直接生成在圖片內，不另加 PowerPoint 文字層。
不要繼承參考圖的範例文案。實際截圖、圖表與照片必須忠實保留。
```

工具若接受本機參考圖，先實際讀取圖片再使用。工具若不接受本機路徑，改用該工具支援的附件方式；不可只寫路徑就假設模型看見圖片。

本專案已實際使用的素材 Prompt 見 `asset-prompts.md`，包含風格總覽與四頁範例。這些可直接修改；改原稿後須重新生圖，僅重新組裝不會改變圖片內的文字。
