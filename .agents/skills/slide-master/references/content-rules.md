# 內容保留與輸入範圍

## 預設約定

一頁原稿對應一頁成品，保留原文、語言、頁序、頁數及可見數值。允許改換行、字體、字級與版面。不同於摘要工具，本 Skill 不會因文字太多就擅自刪字。

## 抽取能做什麼

`extract_deck.py` 支援 PPTX 文字方塊、群組中的文字、表格儲存格與嵌入圖片，輸出 JSON、來源 SHA-256 與媒體檔。文字以形狀由上到下、同高由左到右近似排序；複雜排版需對照原稿確認閱讀順序。表格以列順序保存，不會自動判斷合併儲存格的視覺關係。

腳本保留講者備註，僅提供非可見上下文。母片／版型文字、SmartArt、圖表、公式、影片、OLE、SVG、背景、隱藏頁與動畫不屬於自動重製保證。腳本發現部分複雜物件時會列入 `review_required`；這不是完整偵測器。**生成前仍須對照每頁原稿或原稿渲染，不能將 JSON 視為全部可見內容。**

遇到複雜頁面，先渲染原稿並核對內容，必要時人工補充逐頁記錄。實際圖表、截圖、學生作品與照片需保留來源，不可由生圖模型虛構替代。若 imagegen 無法準確保留證據，說明無法可靠重製並與使用者討論處理；不可自行改用程式拼貼原始圖像。

## 需要內容修改時

只在使用者明確要求的範圍改寫或拆頁，將修改前後內容另存 `changes.md`。不要把講者備註中的待修要求自動當成已批准的內容修改。
