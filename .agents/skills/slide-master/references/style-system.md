# 視覺系統

這是一套原創的科技資訊設計，不綁定 Rinne 角色，也不要求所有題目都出現人物。使用 `assets/style-board.png` 對齊整體視覺。

| 色彩 | 色碼 | 用途 |
|---|---|---|
| 午夜藍 | #090E24 | 深色封面與對比區 |
| 深藍 | #172342 | 標題與結構 |
| 青色 | #16D9EC | 流程、連線與主強調 |
| 洋紅 | #EE4EAD | 少量重點 |
| 白色 | #FFFFFF | 明亮內容頁 |

共用語言：俐落切角、細結構線、克制的光感、玻璃稜鏡、充足留白。文字需大而清楚，距邊界約 5%；正文相當於 20–28 pt，標題約 36–52 pt。這些是視覺目標，圖片內的字級無法由 PPTX 結構直接測量。

| 頁型 | 參考圖 | 選擇時機 |
|---|---|---|
| 深色封面 | `assets/examples/slide-01.png` | 開場與章節重點 |
| 明亮概念 | `assets/examples/slide-02.png` | 定義、組成與分類 |
| 明亮流程 | `assets/examples/slide-03.png` | 有順序的操作或資料流 |
| 深淺比較 | `assets/examples/slide-04.png` | 兩者比較與前後變化 |

依內容選頁型，不固定每四頁循環。一般輸入可以多於或少於四頁。範例裡的圖示只是範例主題，應替換成新內容需要的意象。以內容清楚為先，避免裝飾假文字、整頁細小字、過度發光或每頁重複同一構圖。
